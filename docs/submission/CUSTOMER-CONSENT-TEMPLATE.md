## Publication review

Complete immediately before publishing:

- [ ] selected attribution is respected;
- [ ] quote is exact and within approved channels;
- [ ] transaction fields match the approved list;
- [ ] prompt/artifact fields match the approved list;
- [ ] no private identity remains in filenames, metadata, screenshots, or URLs;
- [ ] no credential, authorization header, session token, OTP, or recovery
      material is present;
- [ ] participant/customer relationship classification is accurate;
- [ ] public evidence references this consent record by opaque ID only;
- [ ] owner approved the final redacted artifact.
